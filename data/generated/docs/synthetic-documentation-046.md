# Getting Started: Installing CloudBox Clients — Expected behavior

## Current documented behavior

This CloudBox 2.1 support note focuses on installing cloudbox clients. Install the desktop client for background sync, or simply use the web app in any modern browser — no installation required. All clients sign in with the same account, and files appear everywhere automatically. CloudBox runs on the web, on Windows 10+, macOS 11+, Linux (since version 2.0), iOS 15+, and Android 10+. For the complete explanation and related topics, consult the maintained Getting Started documentation. This note summarizes that source and does not introduce a separate product policy.
