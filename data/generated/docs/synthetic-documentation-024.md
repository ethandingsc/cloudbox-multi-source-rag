# Desktop Client: Bandwidth and Network Settings — Common questions

## Current documented behavior

This CloudBox 2.1 support note focuses on bandwidth and network settings. LAN sync accelerates transfers between devices on the same local network without going through the cloud. The client lets you throttle upload and download bandwidth per network in Settings > Network, so a metered hotspot is never drained by background syncs. On paid plans, "Smart Sync" learns your working hours and schedules large transfers for off-peak times. For the complete explanation and related topics, consult the maintained Desktop Client documentation. This note summarizes that source and does not introduce a separate product policy.
