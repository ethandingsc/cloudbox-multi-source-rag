# Sharing Files and Folders: Uploading Through the Web App — Common questions

## Current documented behavior

This CloudBox 2.1 support note focuses on uploading through the web app. A web upload that exceeds 2 GB fails partway through with no data saved; you can retry it from the desktop client without corrupting anything. The API also supports uploads up to 20 GB. Uploads made through a browser are capped at 2 GB per file. For larger files, use the desktop or mobile client, which support uploads up to 20 GB. For the complete explanation and related topics, consult the maintained Sharing Files and Folders documentation. This note summarizes that source and does not introduce a separate product policy.
