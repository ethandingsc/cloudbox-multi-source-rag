# Desktop Client: Installing the Desktop Client — Common questions

## Current documented behavior

This CloudBox 2.1 support note focuses on installing the desktop client. After installation, sign in and choose which folders to sync; the default is your entire CloudBox folder with selective sync available for fine control. Download the desktop client from the CloudBox download page. Supported platforms: Windows 10 or newer, macOS 11 or newer, and Linux (Ubuntu 20.04+ / Fedora 36+, via .deb package or AppImage — available since CloudBox 2.0). For the complete explanation and related topics, consult the maintained Desktop Client documentation. This note summarizes that source and does not introduce a separate product policy.
