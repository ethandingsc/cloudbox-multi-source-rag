# Mobile Apps: Mobile Limitations — Expected behavior

## Current documented behavior

This CloudBox 2.1 support note focuses on mobile limitations. Uploads from mobile clients support files up to 20 GB, subject to free-space checks on the device. Files stored offline are encrypted with the device's own disk encryption; the app adds no additional encryption layer. The mobile app does not support selective sync, bandwidth throttling, or LAN sync. For the complete explanation and related topics, consult the maintained Mobile Apps documentation. This note summarizes that source and does not introduce a separate product policy.
