# Sharing Files and Folders: Sharing Files and Folders — Common questions

## Current documented behavior

This CloudBox 2.1 support note focuses on sharing files and folders. By default the link works for anyone who has it; switch to "Specific people" to restrict access to named individuals or groups. To share a file or folder, right-click it in any CloudBox client and choose Share, or use the Share button in the web app. Pick a permission level — View (read-only), Edit (add and modify files), or Comment (read and leave comments) — then copy the generated link. For the complete explanation and related topics, consult the maintained Sharing Files and Folders documentation. This note summarizes that source and does not introduce a separate product policy.
