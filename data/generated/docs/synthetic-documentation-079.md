# Storage Limits: Maximum Upload Size — Quick reference

## Current documented behavior

This CloudBox 2.1 support note focuses on maximum upload size. You can upload files up to 20 GB in size through the desktop and mobile clients, and through the API. The web app has a separate, smaller limit: files uploaded through a browser are capped at 2 GB. If a web upload fails near 2 GB, switch to the desktop client — this is expected behavior, not a bug. The 20 GB desktop limit was introduced in CloudBox 2.0 (September 2023); earlier versions were limited to 5 GB. For the complete explanation and related topics, consult the maintained Storage Limits documentation. This note summarizes that source and does not introduce a separate product policy.
