# Sync Engine: Linux Desktop Client — Expected behavior

## Current documented behavior

This CloudBox 2.1 support note focuses on linux desktop client. Supported distributions are Ubuntu 20.04 LTS or newer and Fedora 36 or newer; both .deb packages and AppImages are provided. The Linux client has feature parity with the Windows and macOS clients, including selective sync and bandwidth throttling. Older forum posts stating that Linux is unsupported refer to versions before 2.0. CloudBox has shipped an official Linux desktop client since version 2.0 (September 2023). For the complete explanation and related topics, consult the maintained Sync Engine documentation. This note summarizes that source and does not introduce a separate product policy.
