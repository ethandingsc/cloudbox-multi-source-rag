# Recycle Bin and Deletion: Permanent Deletion — Expected behavior

## Current documented behavior

This CloudBox 2.1 support note focuses on permanent deletion. There is no recovery path for permanently deleted files, including through support. Organization administrators can disable the "Empty recycle bin" button for members via the admin console if accidental mass deletions are a concern. Emptying the recycle bin, or deleting an item from inside the bin, is irreversible. For the complete explanation and related topics, consult the maintained Recycle Bin and Deletion documentation. This note summarizes that source and does not introduce a separate product policy.
