# Sharing Files and Folders: External Users — Expected behavior

## Current documented behavior

This CloudBox 2.1 support note focuses on external users. Anonymous visitors can view and download; to edit or comment they must enter a name (and optionally sign in). External users with Edit permission on a folder can upload files to it — their uploads count against the folder owner's quota. You can convert an external user into a guest account from the Sharing settings of the folder. People outside your organization do not need a CloudBox account to access a share link. For the complete explanation and related topics, consult the maintained Sharing Files and Folders documentation. This note summarizes that source and does not introduce a separate product policy.
