# API Reference: API Overview — Quick reference

## Current documented behavior

This CloudBox 2.1 support note focuses on api overview. The CloudBox REST API provides programmatic access to files, folders, share links, and account metadata. Authentication uses OAuth2 bearer tokens created in the developer console. Responses are JSON, and all endpoints are versioned under /v1. The API is available on all plans; Business and Enterprise plans receive higher rate limits on request. For the complete explanation and related topics, consult the maintained API Reference documentation. This note summarizes that source and does not introduce a separate product policy.
