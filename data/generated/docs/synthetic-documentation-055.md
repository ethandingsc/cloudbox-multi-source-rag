# Recycle Bin and Deletion: How the Recycle Bin Works — Quick reference

## Current documented behavior

This CloudBox 2.1 support note focuses on how the recycle bin works. When you delete a file or folder in any CloudBox client, it moves to the recycle bin instead of being destroyed. Restoring an item returns it to its original location with its sharing settings intact. Items in the recycle bin do not count against your storage quota, but they remain visible to anyone who had access to the original item's folder. For the complete explanation and related topics, consult the maintained Recycle Bin and Deletion documentation. This note summarizes that source and does not introduce a separate product policy.
