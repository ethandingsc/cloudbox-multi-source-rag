# Sharing Files and Folders: Sharing Files and Folders — What to check

## What the guide says

A practical way to approach sharing files and folders is to start with the current Sharing Files and Folders guide. Pick a permission level — View (read-only), Edit (add and modify files), or Comment (read and leave comments) — then copy the generated link. By default the link works for anyone who has it; switch to "Specific people" to restrict access to named individuals or groups. To share a file or folder, right-click it in any CloudBox client and choose Share, or use the Share button in the web app. When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup.
