# Sync Engine: Sync Conflicts — What to check

## What the guide says

A practical way to approach sync conflicts is to start with the current Sync Engine guide. Nothing is overwritten or lost. To resolve a conflict, compare the two files, decide which to keep, and delete the other. Conflicted copies behave like normal files and sync everywhere. If the same file is edited in two places before either syncs, CloudBox keeps both versions: one keeps the original name and the other becomes "name (conflicted copy, YYYY-MM-DD, user)". When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup. This note is a scenario-oriented summary of the same facts.
