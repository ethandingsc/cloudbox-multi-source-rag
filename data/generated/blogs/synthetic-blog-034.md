# Sharing Files and Folders: External Users — Practical notes

## What the guide says

A practical way to approach external users is to start with the current Sharing Files and Folders guide. People outside your organization do not need a CloudBox account to access a share link. Anonymous visitors can view and download; to edit or comment they must enter a name (and optionally sign in). External users with Edit permission on a folder can upload files to it — their uploads count against the folder owner's quota. You can convert an external user into a guest account from the Sharing settings of the folder. When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup. This note is a scenario-oriented summary of the same facts.
