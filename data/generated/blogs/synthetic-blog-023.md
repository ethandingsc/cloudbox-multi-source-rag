# Desktop Client: Bandwidth and Network Settings — What to check

## What the guide says

A practical way to approach bandwidth and network settings is to start with the current Desktop Client guide. On paid plans, "Smart Sync" learns your working hours and schedules large transfers for off-peak times. LAN sync accelerates transfers between devices on the same local network without going through the cloud. The client lets you throttle upload and download bandwidth per network in Settings > Network, so a metered hotspot is never drained by background syncs.
