## What the guide says

A practical way to approach api overview is to start with the current API Reference guide. Authentication uses OAuth2 bearer tokens created in the developer console. Responses are JSON, and all endpoints are versioned under /v1. The API is available on all plans; Business and Enterprise plans receive higher rate limits on request.
