# API Reference: API Overview — Practical notes

## What the guide says

A practical way to approach api overview is to start with the current API Reference guide. The CloudBox REST API provides programmatic access to files, folders, share links, and account metadata. Authentication uses OAuth2 bearer tokens created in the developer console. Responses are JSON, and all endpoints are versioned under /v1. The API is available on all plans; Business and Enterprise plans receive higher rate limits on request. When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup. This note is a scenario-oriented summary of the same facts.
