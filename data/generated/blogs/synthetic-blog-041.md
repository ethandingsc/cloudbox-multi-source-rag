# Sharing Files and Folders: Uploading Through the Web App — What to check

## What the guide says

A practical way to approach uploading through the web app is to start with the current Sharing Files and Folders guide. For larger files, use the desktop or mobile client, which support uploads up to 20 GB. A web upload that exceeds 2 GB fails partway through with no data saved; you can retry it from the desktop client without corrupting anything. The API also supports uploads up to 20 GB. Uploads made through a browser are capped at 2 GB per file. When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup. This note is a scenario-oriented summary of the same facts.
