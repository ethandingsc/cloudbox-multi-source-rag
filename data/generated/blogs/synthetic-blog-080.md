# Storage Limits: Maximum Upload Size — What to check

## What the guide says

A practical way to approach maximum upload size is to start with the current Storage Limits guide. The web app has a separate, smaller limit: files uploaded through a browser are capped at 2 GB. If a web upload fails near 2 GB, switch to the desktop client — this is expected behavior, not a bug. The 20 GB desktop limit was introduced in CloudBox 2.0 (September 2023); earlier versions were limited to 5 GB. Uploads that exceed the limit fail with the error "File too large". When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup. This note is a scenario-oriented summary of the same facts.
