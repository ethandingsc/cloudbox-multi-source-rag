# Recycle Bin and Deletion: How the Recycle Bin Works — Practical notes

## What the guide says

A practical way to approach how the recycle bin works is to start with the current Recycle Bin and Deletion guide. When you delete a file or folder in any CloudBox client, it moves to the recycle bin instead of being destroyed. Restoring an item returns it to its original location with its sharing settings intact. Items in the recycle bin do not count against your storage quota, but they remain visible to anyone who had access to the original item's folder. When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup. This note is a scenario-oriented summary of the same facts.
