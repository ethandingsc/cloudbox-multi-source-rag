# Sharing Files and Folders: Link Permissions and Expiry — What to check

## What the guide says

A practical way to approach link permissions and expiry is to start with the current Sharing Files and Folders guide. Expired links stop working immediately, and you can revoke any link at any time from the Shared links panel. Changing a file's permissions applies to every link that points to it. Links to folders inherit the folder's permissions. Share links can carry an optional expiration date and an optional password. When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup. This note is a scenario-oriented summary of the same facts.
