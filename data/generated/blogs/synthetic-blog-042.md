## What the guide says

A practical way to approach uploading through the web app is to start with the current Sharing Files and Folders guide. A web upload that exceeds 2 GB fails partway through with no data saved; you can retry it from the desktop client without corrupting anything. The API also supports uploads up to 20 GB. Uploads made through a browser are capped at 2 GB per file. For larger files, use the desktop or mobile client, which support uploads up to 20 GB.
