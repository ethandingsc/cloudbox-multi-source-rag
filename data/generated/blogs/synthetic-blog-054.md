# Mobile Apps: Mobile Limitations — What to check

## What the guide says

A practical way to approach mobile limitations is to start with the current Mobile Apps guide. Uploads from mobile clients support files up to 20 GB, subject to free-space checks on the device. Files stored offline are encrypted with the device's own disk encryption; the app adds no additional encryption layer. The mobile app does not support selective sync, bandwidth throttling, or LAN sync. When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup. This note is a scenario-oriented summary of the same facts.
