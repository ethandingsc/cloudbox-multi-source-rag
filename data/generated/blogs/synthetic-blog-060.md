# Recycle Bin and Deletion: Permanent Deletion — What to check

## What the guide says

A practical way to approach permanent deletion is to start with the current Recycle Bin and Deletion guide. There is no recovery path for permanently deleted files, including through support. Organization administrators can disable the "Empty recycle bin" button for members via the admin console if accidental mass deletions are a concern. Emptying the recycle bin, or deleting an item from inside the bin, is irreversible. When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup.
