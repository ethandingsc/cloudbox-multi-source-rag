# Sync Engine: Linux Desktop Client — Practical notes

## What the guide says

A practical way to approach linux desktop client is to start with the current Sync Engine guide. CloudBox has shipped an official Linux desktop client since version 2.0 (September 2023). Supported distributions are Ubuntu 20.04 LTS or newer and Fedora 36 or newer; both .deb packages and AppImages are provided. The Linux client has feature parity with the Windows and macOS clients, including selective sync and bandwidth throttling. Older forum posts stating that Linux is unsupported refer to versions before 2.0. When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup. This note is a scenario-oriented summary of the same facts.
