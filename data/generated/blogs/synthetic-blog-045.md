# Getting Started: Installing CloudBox Clients — Practical notes

## What the guide says

A practical way to approach installing cloudbox clients is to start with the current Getting Started guide. CloudBox runs on the web, on Windows 10+, macOS 11+, Linux (since version 2.0), iOS 15+, and Android 10+. Install the desktop client for background sync, or simply use the web app in any modern browser — no installation required. All clients sign in with the same account, and files appear everywhere automatically. When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup. This note is a scenario-oriented summary of the same facts.
