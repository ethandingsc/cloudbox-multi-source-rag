# Sync Engine: Local Cache and Disk Usage — What to check

## What the guide says

A practical way to approach local cache and disk usage is to start with the current Sync Engine guide. You can clear it at any time under Settings > Advanced without affecting your files. The cache never counts against your CloudBox storage quota — it is a local, per-device artifact only. The client keeps a local cache of recently changed blocks to make syncs faster; this cache can grow large on busy folders. When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup. This note is a scenario-oriented summary of the same facts.
