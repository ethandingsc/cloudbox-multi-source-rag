# Sharing Files and Folders: Preview and Streaming Limits — A closer look

## What the guide says

A practical way to approach preview and streaming limits is to start with the current Sharing Files and Folders guide. Previews are generated on demand and are not stored. The desktop and mobile clients play video locally, so the 500 MB preview cap does not apply to them. The web app can preview and stream files up to 500 MB, including documents, PDFs, images, and video/audio. Files larger than 500 MB must be downloaded before viewing. When a forum answer or an old screenshot differs, check the maintained documentation before changing your setup. This note is a scenario-oriented summary of the same facts.
