# API Reference: API Overview — A closer look

## What the guide says

A practical way to approach api overview is to start with the current API Reference guide. Responses are JSON, and all endpoints are versioned under /v1. The API is available on all plans; Business and Enterprise plans receive higher rate limits on request. The CloudBox REST API provides programmatic access to files, folders, share links, and account metadata. Authentication uses OAuth2 bearer tokens created in the developer console.
